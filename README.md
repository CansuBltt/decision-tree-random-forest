# Decision Tree and Random Forest Classification

This project implements and compares **Decision Tree** and **Random Forest** classification models using Python and `scikit-learn` on a synthetic dataset.

## Features
- **Data Generation**: Creates a synthetic classification dataset.
- **Decision Tree & Pruning**: Trains a baseline tree and applies pruning to prevent overfitting.
- **Random Forest Ensemble**: Implements an ensemble model (`RandomForestClassifier`).
- **Feature Importance**: Extracts and visualizes feature importance scores.
